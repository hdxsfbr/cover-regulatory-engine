## ADDED Requirements

### Requirement: Cover-aligned presentation
The assessment SHALL use locally served Cover wordmark/favicon assets and a consistent reference-derived neutral palette, typography hierarchy and disclosure icons. Asset provenance SHALL be documented. Status labels, evidence, controls and keyboard behavior SHALL remain available at desktop and mobile widths.

#### Scenario: Branded property workflow
- **WHEN** a user searches, selects and inspects a property
- **THEN** the header, search, results, research cards and project controls use a coherent Cover-aligned presentation with readable labels and visible focus

#### Scenario: Mobile and offline assets
- **WHEN** the interface is viewed at a narrow width or external asset requests are unavailable
- **THEN** the local branding and system typography remain visible, controls remain operable and the page does not horizontally overflow
