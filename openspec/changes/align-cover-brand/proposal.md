# Proposal

## Why
The assessment currently uses an unrelated green palette and a text approximation of Cover's logo. Align the product with the supplied buildcover.com reference while retaining the research workflow.

## What Changes
- Use Cover's public wordmark, favicon and disclosure icon artwork, with recorded provenance.
- Adopt the site's charcoal, white and warm-gray palette, editorial serif heading style and restrained spacing.
- Refine search, navigation, cards, inputs, status badges and mobile layouts without changing regulatory logic or hiding evidence.
- Preserve keyboard controls, contrast, source distinctions and all existing assessment functionality. Regulatory scope is unchanged.

## Capabilities
### New Capabilities
None.
### Modified Capabilities
- `buildability-assessment`: consistent branded presentation with accessible interaction and status distinctions.

## Impact
Frontend CSS, header/intro markup and local public assets; app metadata and favicon; visual/browser verification. No backend or data changes. System typography approximates the reference's commercial/trial typefaces without redistributing those font files.
