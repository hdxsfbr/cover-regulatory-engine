Source: https://buildcover.com/, inspected 2026-10-22 at the user's request for this Cover regulatory-engine prototype.

- `cover-logo.svg`: public header/footer `.svg-logo`, geometry unchanged; white/currentColor fills changed to #202020 for the light app header. Framework attributes removed.
- `plus.svg`: public `.icon-plus` control artwork, geometry unchanged.
